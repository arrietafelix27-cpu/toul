# POS · Nueva venta — carpeta de diseño aprobado

Aprobado por Félix el 18 nov 2026. Esta carpeta es lo que Claude Code debe construir.

- `SPEC.md` — especificación completa (en inglés, para Claude Code).
- `prototipos/` — abre `pos-celular.html` o `pos-pc.html` en el navegador y pruébalo como la app real.
- `capturas/` — cada pantalla en orden del flujo (celular y PC).
- `videos/` — grabación del flujo completo para ver las animaciones.
- `referencias/` — los videos e imágenes de inspiración que mandó Félix.

Los videos no se suben a GitHub (están en `.gitignore`) para no inflar el repositorio.
